# 毕业设计工作区

> **课题**：Transformer 大模型图像分类中的背景依赖分析与抑制研究
> **内容**：冻结 CLIP ViT-B/16，在 Waterbirds 上诊断背景（水面/陆地）依赖，
> 定位背景相关注意力头并定向抑制，用随机抑制做对照，评估有效性与边界。
> **学制基准**：26 周（第 1 周 = 2026-11-09 当周，可按实际起始日整体平移）

## 三类东西分开放

| 类别 | 目录 | 谁产出 | 会变吗 |
|---|---|---|---|
| **指引**（别人给你的规范） | `docs/` | `tools/` 生成 | 少变，改了要重生成 |
| **工作区**（你的产出） | `code/` `data/` `paper/` | 你 | 天天变 |
| **状态**（到哪一步了） | `进度.md` | 你和 AI 共同维护 | 每周变 |

## 从哪开始

1. 读 [`docs/00_总览_先看这个.docx`](docs/00_总览_先看这个.docx) —— 文档地图 + 本周 5 件事 + 要问导师的 6 个问题。
2. 打开 [`docs/07_执行手册_每一步做什么.md`](docs/07_执行手册_每一步做什么.md) —— 从 S01 开始照着做，每步都有"预期结果"。
3. 环境装好后，在 `code/` 里按 [`code/README.md`](code/README.md) 的编号约定写脚本。
4. 每周一更新 [`docs/06_进度追踪表.xlsx`](docs/06_进度追踪表.xlsx) 和 [`进度.md`](进度.md)。

## 一条命令自检现状

```bash
cd tools
python verify_docs.py      # 文档是否完好
python audit.py            # 跨文档引用与数字口径是否自洽
```

## 换了电脑 / 换了 AI 助手？

先读 `CLAUDE.md`（工作区地图 + 坑），再读 `进度.md`（现在做到哪、下一步做什么、哪些决策已定）。
