# paper/ —— 论文写作工作区

> 交付物本身的沉淀地。每个子目录对应一类材料，**不要混放**。

| 目录 | 放什么 | 对应周次 |
|---|---|---|
| `00_开题/` | 开题报告正文、技术路线图源文件（draw.io）、答辩用图片 | W4~W6 |
| `01_文献翻译/` | 选定外文原文 PDF、译文（原文+译文对照排版）、术语表 | W4~W6 |
| `02_正文/` | 毕业论文各章节草稿、最终定稿、查重报告 | W20~W23 |
| `03_图表/` | 论文用的全部图（png + pdf 矢量）、表格 csv 快照 | W16~W19 |
| `04_答辩/` | PPT、演示脚本、问答预案、答辩意见与修改记录 | W24~W26 |

## 命名约定

```
02_正文/
├── 论文_v0.1_20260301.docx      # 版本_日期，日期用 YYYYMMDD
├── 论文_v1.0_定稿.docx
└── 查重报告_20260410.pdf

03_图表/
├── fig_4-5_k_scan_curve.pdf     # 图号与论文一致！fig_章-序_语义名
├── fig_4-5_k_scan_curve.png     # 同名 png（300dpi）
└── tab_4-2_main_results.csv     # 表号与论文一致
```

## 四条规矩

1. **图表名带论文编号**（`fig_4-5_...`），否则写论文时你会找不到哪张图是哪个。
2. **每张图都留源数据**：`03_图表/` 里同名 csv，确保改图能重画。
3. **不覆盖旧版本**：论文每天另存一个新版本，`_v0.x_日期`，别在同一个文件上改到面目全非。
4. **送审/归档前打包**：终稿 docx + pdf + 图表 + 查重报告放同一压缩包。

## 与 docs/ 的区别

- `docs/` = **别人给你的规范与指引**（任务书拆解、文献清单、环境手册、时间计划），只读参考。
- `paper/` = **你自己产出的论文材料**，会不断被修改和版本化。
