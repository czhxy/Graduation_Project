# paper/05_文献/ —— 文献工作区

> 师兄/导师给的参考文献、16 篇清单的原文与阅读笔记，统一放这里。
> 只放「读文献、写论文用的原料」；论文正文在 `../02_正文/`，译文定稿在 `../01_文献翻译/`。

## 目录约定

| 路径 | 放什么 | 进 git 吗 |
|---|---|---|
| `00_原文PDF/` | 官方渠道（OpenReview / PMLR / arXiv / CVF）下载的原文，以及师兄发来的 PDF 工作副本 | ❌ 默认不进（版权 + 体积；`.gitignore` 已排除）；正式备份在 Zotero |
| `01_core/` | 核心 5 篇的精读笔记（`.md`，模板见 `docs/03` §七） | ✅ |
| `02_support/` | 强相关 11 篇的通读笔记 | ✅ |
| `03_on_demand/` | 按需速查笔记（画图、写「相关工作」时随手记） | ✅ |
| `99_translation/` | 英文翻译草稿、术语表；定稿放 `../01_文献翻译/` | ✅ |
| `文献笔记汇总.md` | 16 篇的索引（编号 / 简称 / 状态 / 笔记位置） | ✅ |

## 命名规则（与 `docs/03` §七 一致）

- 笔记：`编号_简称_年份_读法.md` —— 如 `04_TextSpan_2024_精读笔记.md`
- 原文 PDF（16 篇之内）：`编号_简称_年份.pdf` —— 如 `04_TextSpan_2024.pdf`
- 师兄额外给的（不在 16 篇清单里）：`X01_简称_年份.pdf`
- 清单/表格：`YYYYMMDD_来源_文献清单.xlsx` —— 如 `20261110_师兄_文献清单.xlsx`
- 译文：用 `v1 / v2 / final` 版本号，旧版移进 `_old/`，不要覆盖

## 拿到一批参考文献后的正确顺序

1. **先进 Zotero**（S08 已装）：建 `core / support / reading-log` 三个 collection；
   把 PDF 拖进条目自动挂附件。Zotero 库才是防丢的正式备份。
2. 在 `00_原文PDF/` 留一份工作副本（可选；这里默认不进 git）。
3. 通读/精读后写笔记 → 放 `01_core / 02_support / 03_on_demand` → 在 `文献笔记汇总.md` 补一行。
4. 要拿来做英文翻译的那一篇：原文复制到 `paper/01_文献翻译/`（S37 的产出要求）。

## 注意

- **不要**把原文 PDF 或笔记放进 `docs/`：`docs/` 是 `tools/gen_*.py` 生成的指引区，放进去会被覆盖。
- 论文引用一律从 Zotero 导出（GB/T 7714-2015），不要手抄条目。
- 想连 PDF 一起备份到 GitHub（仅限私有库）：删掉 `.gitignore` 里 `00_原文PDF` 那两行即可。
