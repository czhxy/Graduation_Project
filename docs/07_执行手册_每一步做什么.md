## 0. 怎么用这份手册

**三步循环**：做 → 对照「预期结果」→ 记录（更新 `docs/06` 与 `进度.md`）。

- **一次只做一步**。不要跳步，尤其不要跳过 S07（环境自检）和 S36（基线复算）。地基错了后面全错。
- **卡住 30 分钟就停**。先看「不符合预期」；没有就去看 `docs/04` 第 11 章的排查表；还不行就问人。硬扛半天是本项目最大的时间黑洞。
- **每一步都要有产物**。产物写进指定路径，否则等于没做。
- 步骤编号 `S01` 与 `进度.md` 的「当前步骤」对应，换 AI 时按编号接续。

**时间说明**：所有步骤按「第 N 周」组织。第 1 周 = 2026-11-09 当周；若学校进度不同，整体平移即可，步骤内容不变。

**每周节奏建议**（详见 `docs/05` 第 2 章）：平日每天 3 小时、周六 5 小时、周日 2 小时复盘，约 19~20 小时/周。

### S21 · ★ forward hook 基础
`W2` · 3 小时 ★★ 本周最重要

**做什么**：对一个简单模型注册 `register_forward_hook`，在 hook 里打印输出的 shape 并 `return None`。

```python
feats = {}
def hook(module, inp, out):
    feats['x'] = out
    # return None → 不改变前向结果
h = model.some_layer.register_forward_hook(hook)
```

**预期结果**：前向一次后，`feats['x']` 里有该层输出；且**模型原本的输出完全不变**（这一点要用数值确认）。

**不符合预期**：hook 没触发 → 检查是不是在 `no_grad` 下注册的（`no_grad` 不影响 hook）；输出变了 → hook 里错误地 `return` 了一个张量。

**产出**：`code/notebooks/w02_hook_basics.ipynb`
